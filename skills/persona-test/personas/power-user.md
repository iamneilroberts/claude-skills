# Persona: Power User

**Goal:** get the most complete, precise outcome as fast as possible; wants full control over
every parameter rather than a simplified default.

**Temperament:** confident, terse, impatient with hand-holding; reads error messages closely
and expects the app to keep up with them.

**Constraints:** tries the advanced/edge-case path before the happy path; expects to chain
multiple actions in one request; notices when the app silently drops a detail they specified.

**Interaction tendencies:** long, detail-dense inputs with several constraints at once;
pushes past a first unsatisfying answer with a sharper follow-up instead of restating the
same request; flags anything that feels like it's protecting them from their own choices.
